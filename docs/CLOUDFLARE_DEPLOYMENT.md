# 100% Free Cloudflare Pages Edge Deployment Guide

This guide outlines deploying static sites generated by **GravityPress CMS** to **Cloudflare Pages** at zero financial cost, with global edge caching and automated CI/CD.

---

## 2. One-Click CLI Deployment

Run the built-in CLI command to compile static assets to `dist/` and push to Cloudflare Pages:

```bash
gravitypress deploy --target cloudflare --output dist
```

---

## 3. Automated GitHub Actions CI/CD Setup

1. In your Cloudflare Dashboard, obtain your **Account ID** and generate an **API Token** with `Cloudflare Pages:Edit` permissions.
2. In your GitHub repository settings, add the following repository secrets:
   * `CLOUDFLARE_ACCOUNT_ID`
   * `CLOUDFLARE_API_TOKEN`
3. Push to `main`. The included workflow (`.github/workflows/deploy-cloudflare.yml`) automatically builds and publishes the site in under 30 seconds.

---

## 4. Edge Cache Purge via API

When editing articles in the GravityPress Admin Studio, the backend automatically purges the Cloudflare zone cache:

```bash
curl -X POST "https://api.cloudflare.com/client/v4/zones/{zone_id}/purge_cache" \
     -H "Authorization: Bearer {CLOUDFLARE_API_TOKEN}" \
     -H "Content-Type: application/json" \
     --data '{"purge_everything": true}'
```
